# 🚀 Mara ResumeIQ AI

## 📌 Overview

Mara ResumeIQ AI is an AI-powered career development platform designed to help students, fresh graduates, and job seekers improve their professional profiles and increase their chances of securing employment opportunities.

The platform uses Artificial Intelligence to analyze resumes, calculate ATS scores, provide resume improvement suggestions, recommend relevant skills, generate interview questions, recommend jobs, and create professional portfolios automatically.


## ✨ Features

- 📄 AI Resume Analysis
- 📊 ATS Score Evaluation
- 🛠️ Skill Recommendations
- 💼 Job Recommendations
- 📈 Resume Improvement Suggestions
- 🎤 AI Interview Question Generator
- 🤖 AI Career Chatbot
- 🌐 Portfolio Generator
- 🔐 User Authentication
